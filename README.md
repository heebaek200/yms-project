# YMS Project

YMS(YouTube Management System)는 영상 크리에이터와 편집자의 제작 과정에서 발생하는 일정, 작업 배정, 커뮤니케이션, 비용 및 성과 데이터를 하나의 서비스에서 관리하기 위한 프로젝트입니다. PHP와 jQuery 기반의 웹 개발자로 실무를 경험한 뒤 약 6년간 유튜브 채널 운영과 영상 편집 분야에서 쌓은 도메인 경험을 바탕으로 기획했으며, 과거의 웹 개발 경험을 Spring Boot와 React 기반의 모던 풀스택 환경으로 확장하는 것을 목표로 합니다. 단순한 CRUD 포트폴리오를 넘어 실제 영상 제작 현장에서 카카오톡, 스프레드시트, 노션 등에 분산되어 관리되는 업무를 통합하고, 향후 YouTube API를 활용한 영상 성과 분석과 작업자 정산까지 지원하는 실제 배포 가능한 서비스를 지향합니다.
