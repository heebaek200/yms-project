# YMS Project

YMS(YouTube Management System)는 **콘텐츠 제작에 투입한 비용으로부터 얼마의 가치를 만들었는지 관리하는 프로그램**입니다. 유튜브 채널과 미디어 에이전시의 실제 업무를 기준으로 영상 제작 일정, 작업 배정, 커뮤니케이션, 제작비와 정산을 통합하고, 개별 영상뿐 아니라 여러 콘텐츠를 묶는 캠페인 단위로 광고·협찬·제휴·상품 판매·YouTube 플랫폼 수익 등 다양한 수익원을 연결해 제작비 대비 성과를 확인할 수 있도록 설계합니다. PHP와 jQuery 기반의 웹 개발 실무와 약 6년간의 유튜브 채널 운영·영상 편집 경험을 바탕으로 기획했으며, Spring Boot와 React 기반의 모던 풀스택 환경에서 실제 배포 가능한 SaaS로 확장하는 것을 목표로 합니다.
