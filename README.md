# YMS Project

YMS(YouTube Management System)는 **유튜브 크리에이터와 편집자·썸네일 작업자가 영상 제작 과정을 함께 관리하는 협업 서비스**입니다. 영상마다 필요한 작업을 나누고 담당자와 일정을 배정하며, 진행 상태·검수·채팅·정산까지 하나의 흐름으로 관리할 수 있도록 설계합니다. 여기에 크리에이터와 운영자를 위한 확장 기능으로 광고·협찬·제휴·상품 판매·YouTube 플랫폼 수익 등 다양한 수익원과 제작비를 연결하여, **콘텐츠 제작에 투입한 비용으로부터 얼마의 가치를 만들었는지** 프로젝트와 캠페인 단위로 확인할 수 있도록 합니다. PHP와 jQuery 기반의 웹 개발 실무와 약 6년간의 유튜브 채널 운영·영상 편집 경험을 바탕으로 기획했으며, Spring Boot와 React 기반의 모던 풀스택 환경에서 실제 배포 가능한 SaaS로 확장하는 것을 목표로 합니다.
